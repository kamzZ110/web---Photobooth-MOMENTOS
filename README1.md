# Persiapan Web ASELOLE

1. Baca [AGENTS.md](AGENTS.md) dan [PRD Master](design-library/docs/PRD-MASTER.md) untuk ruang lingkup, privasi media, dan acceptance criteria.
2. Gunakan [Alur Produk](design-library/docs/ALUR-PRODUK.md) dan [Decision Log](design-library/docs/DECISION-LOG.md) untuk alur dan keputusan Locked. Detail P04/P05 dan sumber wireframe lama masih tercatat sebagai gap di [audit sumber](design-library/docs/13-stage2b-task1-source-audit.md).
3. Buka [FigCraft Classic v0.10](WEB-ASELOLE-Classic-v0.10.figcraft) untuk desain terkini. Gunakan [Panduan Desain](design-library/docs/PANDUAN-DESAIN.md), [komponen](design-library/docs/03-component-library.md), [token](design-library/tokens), dan [aset Classic](design-library/assets). Rujukan v0.8 dalam dokumen lama adalah riwayat.
4. Mulai dari Solo Classic, lalu Duo. Pakai daftar OPEN di [handoff awal](design-library/docs/04-handoff-open-questions.md) sebagai konteks pembahasan teknis. Status produksi desain pada handoff awal bersifat historis. FLIP-TEST-01 tetap sesudah implementasi Classic.
5. Jalankan acceptance criteria PRD dan [skenario QA](design-library/qa/classic-usability-accessibility-v0.6.md) pada web. Task 6 masih terbuka untuk sesi peserta, aksesibilitas, dan validasi perangkat. Kamera, ekspor file, dan koneksi Duo dua perangkat perlu diuji pada implementasi.

Folder ini berisi salinan pilihan untuk implementasi. Riwayat dan bukti lengkap tersedia di folder proyek induk.
